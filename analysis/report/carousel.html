02 · DEMAND

August 2025: moderators started tagging outages

The outage tag (created early 2024, rarely used) suddenly became standard practice in Aug 2025 — 5–25 uses/month, then 58–109/month ever since. Keyword-classified outage volume rose only ~1.3–1.5× over the same window: the step is mostly moderators getting organised, not a reliability cliff.

07 · THE FIX LIST

Where the leverage is

  1. Self-service recovery for stuck lifecycle ops — force-restart / cancel / rollback + hard timeouts. Resolves the top root cause across all six triage passes.
  2. Support SLA + auto-escalation for prod-down paid plans — kills the "magic keyword" ticket hack.
  3. Honest per-region / per-project status page — no more "All Systems Operational" while databases are down.
  4. Forum answer capacity — staff rotation or AI first-response after 24h of silence. Coverage is good, but one volunteer carries 27% of it.
  5. Degraded-mode dashboard — the control plane fails exactly when the project is sick.
  6. Edge Functions memory playbook + per-invocation memory in logs.
